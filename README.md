# lovinghomes

Welcome to the Loving Homes Dog Hotel Repository. This project is a professional pet boarding and care website built for a dog hotel based in Nairobi, Kenya.

## Features

* **Professional design:** A clean, engaging layout tailored for pet owners.
* **Service details:** Easy access to comprehensive information about boarding and care services.
* **Contact integration:** Simple ways to get in touch or make inquiries.

## Technologies Used

* HTML5
* CSS3

## Installation

Since this is a static website, you can simply clone this repository and open the index.html file in any modern web browser to view it.
